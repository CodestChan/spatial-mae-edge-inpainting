# Spatial MAE Priors and Edge Guidance for Image Inpainting

This repository is the official code repository for the paper:

> **Spatial MAE Priors and Edge Guidance for Image Inpainting**

The project implements a structure-aware latent diffusion inpainting
framework that combines spatial priors from a masked autoencoder (MAE),
visible-edge conditioning through ControlNet, auxiliary edge
reconstruction, and Spatial-Token Attention Loss (STAL).

This repository is being cleaned and documented for public release.
